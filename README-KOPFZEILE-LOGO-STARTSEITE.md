# Kopfzeile – Logo exakt wie auf der Startseite

Dieses Paket korrigiert die einheitliche Kopfzeile aus dem vorherigen Paket.

## Behoben

- Das vollständige Startseitenlogo wird lokal mitgeliefert.
- Das Logo enthält bereits:
  - SVK-Wappen
  - Schriftzug „SpVgg Kaufbeuren e. V.“
- Der Vereinsname wird nicht mehr ein zweites Mal daneben angezeigt.
- Logo-Größe und Header-Höhe entsprechen der Startseite.
- Desktop: 315 px Logo-Breite
- Tablet: 240 px
- Mobil: 210 px beziehungsweise 185 px

## Wirkung

Herren, Jugend, Spielerprofile, News, Historie, Stadion, Sponsoren und
weitere Unterseiten erhalten dieselbe Logo-Darstellung wie die Startseite.

## Upload

1. ZIP entpacken.
2. Alles in das bestehende GitHub-Repository hochladen.
3. Nichts vorher löschen.
4. Gleichnamige Dateien ersetzen lassen.
5. GitHub Pages kurz aktualisieren lassen.
6. Danach Strg/Cmd + Shift + R drücken.

Dieses Paket ersetzt das vorherige Kopfzeilenpaket vollständig.
