## Upload
1. ZIP entpacken.
2. Den gesamten Inhalt in das bestehende GitHub-Repository hochladen.
3. Nichts vorher löschen.
4. Gleichnamige Dateien ersetzen lassen.
5. Die Seite ist danach unter `/herren2/` und `/herren2.html` erreichbar.
6. Falls gewünscht, den Link aus `HINWEIS-LINK-HERREN2.html` zusätzlich in die bestehende Herren-Navigation einfügen.
7. Nach dem Deployment mit Cmd + Shift + R neu laden.
