# SpVgg Kaufbeuren – BFV-Integration für alle Mannschaften

Dieses Paket ergänzt die Mannschaftsseiten um einen einheitlichen, responsiven BFV-Live-Bereich.

## Enthalten

- Herren 1
- U23
- Damen
- U17-Mädchen
- U19 bis G-Jugend
- responsive Darstellung für Handy, Tablet und Desktop
- vorbereitete Plätze für Spielplan, Ergebnisse, Tabelle, Torschützen und Liveticker
- zentrale Checkliste `BFV-WIDGET-CODES.md`

## Wichtig

Die individuellen BFV-Widget-Codes sind an eine registrierte Domain und den BFV-Login des Vereins gebunden.
Sie können deshalb nicht seriös vorausgefüllt oder erfunden werden.

Nach der einmaligen Erstellung und Einbindung aktualisieren sich die Daten automatisch direkt über den BFV.

## Upload

1. ZIP entpacken.
2. Gesamten Inhalt ins bestehende GitHub-Repository hochladen.
3. Nichts löschen.
4. Gleichnamige Dateien ersetzen.
5. Danach die BFV-Codes gemäß `BFV-WIDGET-CODES.md` einsetzen.
