# Newsbereich V1

Enthalten:
- moderne News-Übersicht
- großes Top-Thema
- Filter nach Herren, Jugend, Verein und Veranstaltungen
- Suchfunktion
- sechs News-Detailseiten
- Newsletter-Design als Prototyp
- responsive Ansicht für Handy, Tablet und Desktop

## Wichtig
Der Newsletter versendet derzeit noch keine E-Mails. Dafür muss nach der Vereinsfreigabe
ein Dienst wie Brevo, Mailchimp oder ein TYPO3-Newslettermodul angebunden werden.

## Upload
1. ZIP entpacken.
2. Alles in das bestehende GitHub-Repository hochladen.
3. Nichts vorher löschen.
4. Gleichnamige Dateien ersetzen lassen.
5. Nach dem Deployment mit Cmd + Shift + R neu laden.
