SVK V42 – GLOBALER HEADER + REDAKTIONS-LOGIN

Dieses Paket aktualisiert den globalen Header.

NEU:
- Einheitliche Kopfleiste auf allen Seiten, die assets/js/svk-global-header.js laden.
- Dunkelblaue obere Leiste wie auf der Startseite.
- Kleiner Button "Anmelden" oben rechts.
- Der Button führt zu: redaktion/index.html
- Kontakt und Partner bleiben in der oberen Leiste.
- Doppelte/alte Seitenheader werden automatisch entfernt.
- Verein-Dropdown bleibt erhalten.
- Mobil optimiert.

WICHTIG:
Damit der Header auf wirklich jeder HTML-Seite erscheint, muss diese Seite
assets/js/svk-global-header.js laden. Seiten, die das Script noch gar nicht
einbinden, können durch dieses Paket allein nicht automatisch verändert werden.

UPLOAD:
1. ZIP entpacken.
2. assets/js/svk-global-header.js ersetzen.
3. assets/css/svk-global-header.css ersetzen.
4. Commit.
5. GitHub Pages deployen lassen.
6. Safari: Cmd + Option + R.

Falls eure funktionierende Login-Datei anders heißt als redaktion/index.html,
muss nur der Link im JS angepasst werden.
