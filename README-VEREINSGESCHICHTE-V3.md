# Vereinsgeschichte V3 – Museumsausbau

Dieses Komplettpaket enthält V1, das Bayern-Bild aus V2 und den Museumsausbau aus V3.

## Neu enthalten
- Abschnitt zu Abstiegen, Neuaufbau und Rückkehr
- Bayern-Bild von 2009 an der richtigen Stelle
- grafischer Ligaverlauf
- aufklappbares digitales SVK-Museum
- Hall of Fame
- historische Galerie
- vorbereitete Bereiche für:
  - Mannschaftsfotos
  - Trikots und Wappen
  - Eintrittskarten
  - Zeitungsartikel
  - Vereinslegenden
- optimierte Handyansicht

## Hinweis
Die Formulierung zur heutigen Liga ist bewusst allgemein gehalten, weil die genaue
offizielle Ligabezeichnung später noch endgültig bestätigt werden kann.

## Upload
1. ZIP entpacken.
2. Alles in das bestehende GitHub-Repository hochladen.
3. Nichts vorher löschen.
4. Gleichnamige Dateien ersetzen lassen.
5. Nach dem Deployment mit Cmd + Shift + R neu laden.
