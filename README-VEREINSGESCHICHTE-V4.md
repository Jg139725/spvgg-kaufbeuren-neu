Dieses Paket ersetzt die bisherige Historien-Version vollständig.

- feste Epochen-Navigation
- fünf ausführliche Zeitabschnitte:
  - 1909–1945
  - 1945–1963
  - 1963–1976
  - 1976–2012
  - 2012–Heute
- vollständigerer Ligaverlauf
- Aufstiege und Abstiege
- Amateurliga- und Landesliga-Jahre
- Bezirksoberliga-Zeit

  - Franz „Bulle“ Roth
  - Hermann Albrecht

- digitales Vereinsarchiv
- bestehendes SVK-Museum
- Hall of Fame
- historische Galerie
- Kopfzeile passend zur Startseite
- mobile Optimierung

## Transparenz

Unsichere oder noch nicht vollständig belegte Detailrekorde wurden nicht erfunden.
Das Archiv ist so vorbereitet, dass Vereinsmaterial später ergänzt werden kann.

## Upload

1. ZIP entpacken.
2. Alles in das bestehende GitHub-Repository hochladen.
3. Nichts vorher löschen.
4. Gleichnamige Dateien ersetzen lassen.
5. GitHub Pages aktualisieren lassen.
6. Danach Strg/Cmd + Shift + R drücken.
