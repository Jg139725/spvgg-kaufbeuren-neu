# Jugendleitung – Öffnungsstatus Autofix

Dieses Paket behebt den Fehler, dass der Status dauerhaft „geschlossen“ anzeigt.

## Behoben
- zuverlässige Erkennung des Wochentags
- feste Zeitzone Europe/Berlin
- automatische Aktualisierung jede Minute
- erneute Prüfung beim Wechsel zurück in den Browser-Tab
- korrekter Wechsel zwischen grün und rot

## Öffnungszeiten
- Montag bis Donnerstag: 16:00–20:00 Uhr
- Freitag: 16:00–18:00 Uhr
- Samstag und Sonntag: geschlossen

## Upload
1. ZIP entpacken.
2. Den enthaltenen Ordner `assets` hochladen.
3. Die vorhandene Datei ersetzen:
   `assets/js/jugend-office-status.js`
4. GitHub Pages fertig aktualisieren lassen.
5. Danach Strg/Cmd + Shift + R drücken.
