# Fanshop – Textilstars final

Dieses Paket ersetzt den bisherigen falschen Fanshop-Link vollständig.

## Neuer offizieller Link
https://textilstars.com/SpVgg-Kaufbeuren

## Verhalten
- Der Menüpunkt `Fanshop` öffnet direkt den Textilstars-Shop.
- Der Shop öffnet sich in einem neuen Tab.
- Alle bisherigen Fan12-Verweise wurden entfernt.
- `fanshop.html` dient weiterhin als kurze Absicherung und leitet ebenfalls zu Textilstars weiter.
- Das bestehende Design der Website bleibt unverändert.

## Upload
1. ZIP entpacken.
2. Alles in das bestehende GitHub-Repository hochladen.
3. Nichts vorher löschen.
4. Gleichnamige Dateien ersetzen lassen.
5. GitHub Pages kurz aktualisieren lassen.
6. Danach mit Strg/Cmd + Shift + R neu laden.
