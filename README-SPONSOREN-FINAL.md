# Finales Sponsorenpaket

Dieses Paket behebt alle bisher genannten Sponsorenprobleme.

## Behoben
- echte Logos lokal gespeichert
- Logos auf der Startseite sichtbar
- Logos auf der Sponsoren-Seite sichtbar
- keine unsicheren Filter oder Kategorien mehr
- alle Sponsoren gleichwertig dargestellt
- alle Logos anklickbar
- automatische Rotation wie bei modernen Vereinsseiten
- Rotation pausiert beim Darüberfahren
- barrierearme Alternative bei reduzierten Animationen
- Handy- und Desktopansicht

## Enthaltene Sponsoren
- Aktienbrauerei Kaufbeuren
- Sparkasse Allgäu
- Haumayr & Sohn
- Ansorge Logistik
- Finsterwalder
- Falcetta Pizzeria
- VR Bank Augsburg-Ostallgäu
- HAWE Hydraulik
- Heinle Elektrotechnik

## Upload
1. ZIP entpacken.
2. Alles in das bestehende GitHub-Repository hochladen.
3. Nichts vorher löschen.
4. Gleichnamige Dateien ersetzen lassen.
5. Nach dem Deployment mit Cmd + Shift + R neu laden.
