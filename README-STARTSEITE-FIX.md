# Startseiten-Fix – ursprüngliches Design

Dieses Paket stellt die frühere, hochwertige Startseite wieder her.

## Wichtig
Die Startseite verwendet jetzt eigene Dateien:

- `css/home.css`
- `js/home.js`

Dadurch können Jugend-Updates mit `assets/css/youth.css` oder allgemeine
Unterseiten die Startseite künftig nicht mehr verändern.

## Enthalten
- ursprüngliches großes Hero-Design
- Spieltagskarte
- moderne News-Karten
- Mannschaftsbereiche
- Sponsorenbereich
- Desktop-, Tablet- und Handy-Layout
- interne Navigation zu Jugend, Verein, News und Fanshop

## Upload
1. ZIP entpacken.
2. Den gesamten Inhalt in dein bestehendes Repository hochladen.
3. Nichts vorher löschen.
4. Gleichnamige Dateien ersetzen lassen.
5. Commit changes anklicken.
6. Nach dem Deployment mit Cmd + Shift + R neu laden.
