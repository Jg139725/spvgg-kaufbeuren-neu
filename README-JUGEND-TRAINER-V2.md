## Upload zu GitHub

1. ZIP entpacken.
2. Den gesamten Inhalt in das Hauptverzeichnis des Repositorys hochladen.
3. Nichts vorher löschen.
4. Gleichnamige Dateien ersetzen lassen.
5. `Commit changes` anklicken.
6. GitHub Pages 1–3 Minuten aktualisieren lassen.
7. Danach im Browser:
   - Windows: Strg + F5
   - Mac: Cmd + Shift + R
