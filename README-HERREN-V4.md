# Herren V4 – echte Spielerfotos

Dieses Paket ergänzt 33 echte Spielerfotos aus der bereitgestellten SpielPlus-Liste.

## Enthalten
- 33 Spielerbilder
- vollständiger Kader in der Reihenfolge des SpielPlus-Exports
- moderne responsive Spielerkarten
- Desktop-, Tablet- und Handyansicht
- Trainerbereich und Herren-V3-Design bleiben erhalten

## Wichtig
Positionen und Rückennummern wurden nicht erfunden. Die Zuordnung steht zusätzlich
in `SPIELERFOTO-ZUORDNUNG.md`.

## Upload
1. ZIP entpacken.
2. Den gesamten Inhalt in das bestehende GitHub-Repository hochladen.
3. Nichts vorher löschen.
4. Gleichnamige Dateien ersetzen lassen.
5. Nach dem Deployment mit Cmd + Shift + R neu laden.
