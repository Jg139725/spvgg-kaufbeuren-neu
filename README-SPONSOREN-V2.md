# Sponsoren V2 Komplettpaket

Dieses Paket enthält den ersten Sponsorenentwurf und die erweiterte Premium-Version gemeinsam.

## Enthalten
- moderne Sponsoren-Startseite
- Haupt- und Premiumpartner
- Partnerkategorien mit Filter
- vorbereitetes Sponsorenkarussell
- Bereich „Sponsor werden“
- Sponsoringvorteile
- Kontaktbereich
- Handy-, Tablet- und Desktoplayout

## Noch zu ergänzen
Die Platzhalter `LOGO` und `Partnername` werden später durch die echten Sponsorenlogos,
Unternehmensnamen und Links ersetzt.

## Upload
1. ZIP entpacken.
2. Alles in das bestehende GitHub-Repository hochladen.
3. Nichts vorher löschen.
4. Gleichnamige Dateien ersetzen lassen.
5. Nach dem Deployment mit Cmd + Shift + R neu laden.
