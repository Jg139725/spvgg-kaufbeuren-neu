# SVK Frauen V4 – Layout wie restliche Website

Dieses Paket korrigiert genau die Punkte aus dem Screenshot:

- Frauen-Kopfzeile entfernt
- stattdessen dieselbe globale SVK-Kopfzeile wie bei Herren
- gleiche Inhaltsbreite wie Herren
- gleicher Hero-Aufbau / gleiche Typografie
- Bereichsnavigation als kompakte Pills statt großer linker Sidebar
- Spielerinnenkarten optisch an die Herren-Spielerkarten angeglichen
- PC, Laptop, Tablet und Smartphone neu abgestimmt
- horizontaler Überlauf verhindert
- bisher eingebundene echte Frauenfotos bleiben erhalten

## Wichtig zu den alten Spielerinnenfotos
Die alte Vereinsseite ist als Website nicht mehr Bestandteil des neuen Auftritts.
In den aktuell verfügbaren Projektdateien lagen keine sauber lokal gespeicherten
Einzelportraits aller Damen aus der alten Seite vor. Deshalb wurden keine Bilder
geraten oder einer falschen Spielerin zugeordnet.

Wenn die alten Originalbilder später als Dateien vorliegen, können sie direkt unter
`assets/images/frauen/spieler/` abgelegt und ohne Layoutänderung eingesetzt werden.

## Upload
1. ZIP entpacken
2. gesamten Inhalt in `spvgg-kaufbeuren-neu` hochladen
3. gleichnamige Dateien ersetzen
4. Commit Changes
5. GitHub Pages aktualisieren lassen
6. Cmd + Shift + R
