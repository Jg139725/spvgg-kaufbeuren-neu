Datenschutz auf dieser Website

Verantwortlich für die Vereinsinhalte: SpVgg Kaufbeuren e. V., Berliner Platz 6, 87600 Kaufbeuren. Kontakt: info@spvgg-kaufbeuren.de.

Aufruf der Website

Die Website wird über GitHub Pages bereitgestellt. Beim Aufruf können technische Verbindungsdaten wie die IP-Adresse an den Hosting-Anbieter übertragen werden. Einige Seiten laden Schriftarten von Google Fonts und Spielerbilder von FuPa. Die News-Übersicht lädt veröffentlichte Meldungen vom GitHub-Repository nach.

Externe Inhalte und Links

Beim Anklicken externer Links, etwa zu YouTube, Google Maps, FuPa oder dem bisherigen Vereinsauftritt, gelten die Datenschutzinformationen der jeweiligen Anbieter.

Kontakt und Redaktion

Wenn du per E-Mail Kontakt aufnimmst, werden die übermittelten Angaben zur Bearbeitung der Anfrage verwendet. Redakteurinnen und Redakteure melden sich über GitHub an; das GitHub-Konto und die dort eingereichten News-Formulare werden von GitHub verarbeitet.
