# Parkstadion V3 – finales Bilderpaket

Dieses Paket erweitert die Stadionseite mit den bereitgestellten Fotos und korrigiert die schematische Übersicht.

## Neu
- Luftaufnahme als Hero-Bild
- große Galerie mit Tribüne, Panorama, Laufbahn, Flutlicht und Eingang
- zusätzlicher Bereich „Das Parkstadion im Wandel“
- korrigierter Stadionplan:
  - Haupttribüne oben
  - kleine Tribüne unten
  - Einlass rechts mittig
  - Bahnhof links
  - Innenstadt rechts beim Eingang
  - Jordanpark hinter der Haupttribüne
  - ESVK-Stadion links unten
- mobile Darstellung optimiert

## Hinweis zu den Bildern
Wasserzeichen und Urheberhinweise wurden nicht entfernt.

## Upload
1. ZIP entpacken.
2. Gesamten Inhalt in das bestehende GitHub-Repository hochladen.
3. Nichts vorher löschen.
4. Gleichnamige Dateien ersetzen lassen.
5. Nach dem Deployment mit Cmd + Shift + R neu laden.
