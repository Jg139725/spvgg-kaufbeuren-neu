# Navigation- und Layout-Fix

Dieses Update behebt die unterschiedlichen Mannschafts-Links und Logos.

## Startseite
Die drei Mannschaftskacheln führen jetzt korrekt zu:
- Herren → `herren/index.html`
- Frauen / Mädchen → `frauen/index.html`
- Junioren → `jugend/index.html`

Der Menüpunkt „Mannschaften“ oben scrollt weiterhin absichtlich zum Mannschaftsbereich
der Startseite. Von dort führen alle Kacheln in die passenden modernen Bereiche.

## Einheitliches Design
- Herren, Frauen, News, Verein, Förderverein und weitere Unterseiten verwenden jetzt
  dasselbe SpVgg-Kaufbeuren-Logo wie Start- und Jugendseite.
- Navigation, Abstände und mobile Darstellung bleiben einheitlich.
- Die schöne Startseite bleibt erhalten.

## Upload
1. ZIP entpacken.
2. Den gesamten Inhalt ins bestehende GitHub-Repository hochladen.
3. Nichts löschen.
4. Gleichnamige Dateien ersetzen lassen.
5. Nach dem Deployment mit Cmd + Shift + R neu laden.
