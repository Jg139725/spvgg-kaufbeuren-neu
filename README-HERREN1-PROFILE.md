# 1. Herren – Positionsbereiche und Spielerprofile

## Geändert
- keine Filter mehr
- feste Bereiche:
  - Torwart
  - Abwehr
  - Mittelfeld
  - Angriff
- jede Spielerkarte ist anklickbar
- für jeden Spieler wurde ein eigenes Profil vorbereitet
- keine Videoanimationen eingebaut
- Position, Rückennummer, Spiele, Tore und Assists
- öffentlich belegbare Laufbahndaten aus FuPa
- direkte Links zu den FuPa-Profilen
- vorhandene lokale Spielerfotos bleiben erhalten
- bei fehlendem Foto erscheint ein neutraler Platzhalter

## Zielseiten
- `herren/erste.html`
- `herren/kader.html`
- `herren/spieler/<spielername>.html`

## Hinweis
Einige FuPa-Profile enthalten nur unvollständige oder sehr kurze Laufbahndaten.
Diese Stellen sind offen gekennzeichnet und wurden nicht erfunden.

## Upload
1. ZIP entpacken.
2. Alles in das GitHub-Repository hochladen.
3. Gleichnamige Dateien ersetzen.
4. GitHub Pages fertig aktualisieren lassen.
5. Mit Strg/Cmd + Shift + R neu laden.
