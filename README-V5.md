# SVK Frauen V5 – Mockup-Layout mit echten Kaderfotos

Dieses Paket baut den Damen-Kader nach dem zuerst vorgeschlagenen Mockup auf:
- großer Bild-Hero
- Tabs direkt unter dem Hero
- Mannschaftsinfo + Saisonfakten
- kompakte Spielerinnenkarten
- Trainerteam rechts
- Kapitäninnenbox
- Schnellzugriff
- responsive Desktop / Tablet / Handy
- globale SVK-Kopfzeile wie im Herrenbereich

## Bildquelle
Die alte SVK-Kaderseite verweist auf FuPa. Für die Spielerinnen wurden die dort aktuell
hinterlegten, namentlich zugeordneten Kaderbilder verwendet. Die Bilder werden über
`image.fupa.net` geladen; es gibt keinen Rücklink auf die alte SVK-Webseite.
