# BFV-WIDGET-CODES – Checkliste

Domain für den BFV registrieren:

`https://jg139725.github.io`

Der BFV verlangt eine registrierte Website und erzeugt pro Mannschaft einen individuellen Widget-Code.

## Empfohlene Einstellungen pro Mannschaft

- Widget: Mannschafts-Widget
- Breite: 100 %
- Höhe: mindestens 650 px
- Start-Reiter: Spiele
- Vereinsfarbe: Blau `#0753A5`
- Hintergrund: Weiß `#FFFFFF`
- Schrift: Dunkelblau `#021F46`

## Vorgehen pro Mannschaft

1. Auf BFV.de den Verein „SpVgg Kaufbeuren“ öffnen.
2. Die gewünschte Mannschaft auswählen.
3. Unterhalb der Spieldaten „BFV-Widget generieren“ anklicken.
4. Mit der für `https://jg139725.github.io` registrierten Website anmelden.
5. Mannschafts-Widget erstellen.
6. Den Code aus „Include“ einmal in den Head-Bereich der jeweiligen HTML-Datei einfügen.
7. Den Code aus „Script“ an der markierten Stelle im BFV-Bereich einfügen.
8. Committen und auf Handy sowie Desktop testen.

Der Include-Code darf laut BFV nur einmal pro HTML-Seite eingebunden werden.
