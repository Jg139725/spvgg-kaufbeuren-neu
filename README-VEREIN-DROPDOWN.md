# Verein-Dropdown – Navigation

Dieses Paket räumt die Hauptnavigation auf.

## Geändert
- der eigenständige Menüpunkt `Vorstand` wird entfernt
- `Verein` erhält ein Dropdown mit:
  - Übersicht
  - Vorstand
  - Historie
  - Ansprechpartner
  - Mitglied werden
  - Satzung

## Verhalten
- Desktop: Dropdown bei Mausbewegung über `Verein`
- Handy/Tablet: Dropdown per Antippen
- Startseite, Herren, Jugend und alle anderen Seiten behalten ihre normale Kopfzeile
- die Vorstand-Seite selbst bleibt unverändert

## Hinweis
Falls einzelne Zielseiten wie `mitglied-werden.html` oder `satzung.html`
noch nicht vorhanden sind, können sie später ergänzt werden. Die Navigation
ist dafür bereits vorbereitet.

## Upload
1. ZIP entpacken.
2. Den Ordner `assets` vollständig hochladen.
3. Gleichnamige Dateien ersetzen.
4. GitHub Pages fertig aktualisieren lassen.
5. Danach Cmd + Shift + R oder Strg + F5 drücken.
