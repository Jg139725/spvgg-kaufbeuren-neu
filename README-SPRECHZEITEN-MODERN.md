# Moderne Sprechzeiten

Dieses Update ersetzt den bisherigen Öffnungszeiten-Bereich durch:

- modernes zweispaltiges Desktop-Layout
- kompakte Handyansicht
- automatische Anzeige „Jetzt geöffnet“ oder „Derzeit geschlossen“
- E-Mail-Button
- klar erkennbare Zeiten und Ruhetage

## Upload
ZIP entpacken, alles hochladen, nichts löschen und gleichnamige Dateien ersetzen.
