# Herren V3 – Modernes Redesign

Dieses Paket ersetzt den bisherigen Herrenbereich durch eine deutlich modernere Darstellung.

## Enthalten
- großes Hero-Bild
- moderne Trainerkarten
- hochwertigere Spielerkarten
- öffentlich gelisteter Teilkader 2025/26
- Herren 1
- Herren 2 / U23
- Spielplan-Platzhalter für spätere BFV-Integration
- Newsbereich
- responsive Darstellung für Handy, Tablet und Desktop

## Upload
1. ZIP entpacken.
2. Den gesamten Inhalt in das bestehende Repository hochladen.
3. Nichts vorher löschen.
4. Gleichnamige Dateien ersetzen lassen.
5. Nach dem Deployment mit Cmd + Shift + R neu laden.
