SVK V74 – Responsive Layout (Handy / Tablet / Desktop)
=======================================================
Grundlage: spvgg-kaufbeuren-neu-main-10.zip

Installation:
1. ZIP entpacken.
2. Den gesamten INHALT des ZIPs mit gleichen Pfaden in das GitHub-Repository kopieren.
3. Vorhandene HTML-Dateien ersetzen und die beiden neuen CSS-Dateien hinzufügen.
4. GitHub Pages Deployment abwarten, Safari/Chrome ggf. hart neu laden.

Umfang:
- Responsive Layout-Layer für 144 öffentliche HTML-Seiten.
- Eigene responsive Regeln für die Redaktionsoberfläche.
- Flexible Abstände, Raster, Medien, Footer, Eingabefelder und Navigation auf schmalen Displays.
- Keine Änderungen an Sponsor-Animation, Sponsorendaten, JavaScript oder Supabase.
- Keine inhaltlichen Änderungen an Texten oder Vereinsseiten.

Prüfen:
- Handy: 375px und 430px
- Tablet: 768px und 1024px
- Desktop: 1440px
- Besonders: Startseite/Sponsoren-Animation, Förderverein, News, Mannschaften, Redaktion.
- Das Paket ist eine CSS-Anpassung, keine echte Browser-Gerätetestung. Bei einzelnen
  Sonderlayouts können nach Screenshots noch gezielte Nachbesserungen nötig sein.

Hinweis: Die zuletzt gemeldeten Berechtigungen und Sponsor-Logo-Verwaltung werden durch
dieses Responsive-Paket nicht verändert.
