# Herren Premium Karten – einheitliches Design

Dieses Paket vereinheitlicht die Spielerkarten von 1. und 2. Herren.

## 1. Herren
- kompletter Kartenbereich anklickbar
- Linktext „Spielerprofil öffnen“ entfernt
- große Rückennummer als Hintergrundelement
- Position als Badge
- Spiele, Tore und Assists direkt in der Karte
- moderner Hover-Effekt
- bestehende Profile bleiben erhalten

## 2. Herren
- dasselbe Kartenformat wie 1. Herren
- Name, Badge und Statistikleiste
- Justin bleibt anklickbar
- andere Spieler bleiben weiterhin gesperrt und zeigen „Profil folgt“

## Upload
1. ZIP entpacken.
2. Alles in das bestehende GitHub-Repository hochladen.
3. Gleichnamige Dateien ersetzen.
4. GitHub Pages aktualisieren lassen.
5. Danach Strg/Cmd + Shift + R.
