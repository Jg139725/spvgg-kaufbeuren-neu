# Sponsoren V3 – alle Partner

Dieses Paket ergänzt alle Sponsoren, die aktuell auf der offiziellen SVK-Website
im Sponsorenbereich verlinkt sind.

## Enthalten

- Aktienbrauerei Kaufbeuren
- Sparkasse Allgäu
- Haumayr & Sohn
- Ansorge Logistik
- Finsterwalder
- kochen-lassen.info
- VR Bank Augsburg-Ostallgäu
- HAWE Hydraulik
- Heinle Elektrotechnik

Jede Sponsorenkarte ist anklickbar und öffnet die jeweilige offizielle Unternehmenswebsite
in einem neuen Browserfenster.

## Logos

Die Logos werden über öffentliche Markenbild-URLs geladen. Falls ein Logo einmal nicht
verfügbar ist, erscheint automatisch der Unternehmensname als sauberer Text-Fallback.

## Upload

1. ZIP entpacken.
2. Alles in das bestehende GitHub-Repository hochladen.
3. Nichts vorher löschen.
4. Gleichnamige Dateien ersetzen.
5. Mit Cmd + Shift + R neu laden.
