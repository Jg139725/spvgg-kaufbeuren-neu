# SVK Frauen – Responsive Layout V3

Dieses Paket behebt speziell das im Screenshot sichtbare Layoutproblem.

## Behoben
- kein horizontaler Scrollbalken mehr auf Desktop
- Inhalt bleibt innerhalb der Bildschirmbreite
- Desktop-Layout für große und kleinere Monitore
- Tablet-Layout
- Smartphone-Layout
- Spieler-Karten auf Tablet zweckmäßig angeordnet
- Spieler-Karten auf kleinen Handys kompakt untereinander
- Sidebar wird auf dem Handy zu einer horizontalen Bereichsnavigation
- Faktenkarten BOL / Saison / Parkstadion brechen sauber um
- Spiele passen sich der Displaybreite an
- Kapitäninnen-Bildblock responsive
- funktionierendes Hamburger-Menü auf dem Handy
- bestehende Fraueninhalte und Bilder bleiben erhalten
- keine Verlinkung zur alten SVK-Website

## Einfügen
1. ZIP entpacken.
2. Den kompletten Inhalt in `spvgg-kaufbeuren-neu` hochladen.
3. Gleichnamige Dateien ersetzen.
4. Commit Changes.
5. GitHub Pages kurz aktualisieren lassen.
6. Safari: Cmd + Shift + R.

Wichtig: Nichts anderes aus dem Repository löschen.
