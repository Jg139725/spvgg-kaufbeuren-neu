# Vereinsgeschichte V1

Dieses Paket ergänzt eine vollständige Vereinsgeschichte-Seite und macht sie auf der Startseite sichtbar.

## Enthalten
- neuer Navigationspunkt „Historie“
- Startseiten-Teaser zur Vereinsgeschichte
- interaktive Zeitleiste von 1909 bis heute
- Amateurliga- und Landesliga-Epochen
- Schwabenpokal-Erfolge
- Franz „Bulle“ Roth
- Hermann Albrecht
- ausführlicher Bereich zum Spiel gegen den FC Bayern München 2009
- Erfolge und Titel
- Quellenbereich
- responsive Handy-, Tablet- und Desktopansicht

## Historische Fakten
Es wurden nur öffentlich belegte Angaben verwendet. Weitere Bilder, Vereinsunterlagen
und Zeitzeugenberichte können später ergänzt werden.

## Upload
1. ZIP entpacken.
2. Alles in das bestehende GitHub-Repository hochladen.
3. Nichts vorher löschen.
4. Gleichnamige Dateien ersetzen lassen.
5. Nach dem Deployment mit Cmd + Shift + R neu laden.
