# Kompletter Jugendbereich – SVK-Daten

Dieses Paket basiert auf den aktuell veröffentlichten Jugendseiten der offiziellen SpVgg-Kaufbeuren-Website.

Enthalten:
- Jugendübersicht und Jugendleitung
- U19, U17, U15, U13, U12, U11, U10, U09, U08 und G-Jugend
- veröffentlichte Trainer und Telefonnummern
- veröffentlichte Trainingszeiten und Trainingsorte
- offizielle Bilder, soweit auf der SVK-Website veröffentlicht und technisch zugänglich
- responsive Handy-, Tablet- und Desktopansicht

Wichtig:
- Für U08 waren auf der offiziellen Website aktuell keine eindeutig auslesbaren Trainer- und Kontaktdaten verfügbar. Dort wird bewusst auf die Jugendleitung verwiesen.
- Keine Nummer wurde erfunden.
- Vor der endgültigen TYPO3-Veröffentlichung sollten die Daten noch einmal vereinsintern freigegeben werden.

Upload:
1. ZIP entpacken.
2. Alles in das bestehende Repository hochladen.
3. Nichts vorher löschen.
4. Gleichnamige Dateien ersetzen.
5. Nach dem Deployment mit Cmd + Shift + R neu laden.
