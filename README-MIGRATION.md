# SVK – Migration alte Website → neue Website V1

## Ziel
Ab dem Relaunch ist `jg139725.github.io/spvgg-kaufbeuren-neu` die gepflegte Hauptseite.
Die alte TYPO3-Seite wird **nicht** als laufende Datenquelle und **nicht** als Ziel für interne Links verwendet.

## Bewusst NICHT blind übernommen
### Veraltete PDF-Dateien
Auf der alten Website liegen unter anderem:
- Aufnahmeantrag Stand 09/2023
- Einverständniserklärung Stand 05/2015
- Satzung Fassung 24.09.2013
- ältere BFV-Passanträge / Schadenmeldung

Diese Dateien werden in diesem Paket nicht als „aktuell“ ausgegeben.
Bevor sie lokal auf der neuen Website veröffentlicht werden, sollte der Verein die jeweils gültige Fassung bestätigen.

### U16-II
Der alte Pfad für U16-II leitet inzwischen auf die U17 weiter. Deshalb wurde keine fiktive oder veraltete U16-II-Seite erzeugt.

## Installation
Den Inhalt dieses ZIPs in die oberste Ebene des GitHub-Repositories
`Jg139725/spvgg-kaufbeuren-neu` hochladen und vorhandene gleichnamige Dateien ersetzen.

Das Paket verändert **keine Herren-Spielerkarten oder Herren-Kaderdateien**.

## Unabhängigkeit von der alten Website
Die neuen HTML-Dateien enthalten keine Links auf `alte SVK-Website`.
E-Mail-Adressen mit `@spvgg-kaufbeuren.de` bleiben selbstverständlich bestehen.
