# Design-Reparatur

Dieses Paket behebt das Problem, dass das Jugend-Update die Startseite und andere Bereiche optisch verändert hat.

## Was geändert wird

- `assets/css/style.css`
  - stellt das gute allgemeine Design der Startseite und übrigen Website wieder her

- `assets/css/youth.css`
  - enthält ausschließlich das moderne Jugend- und U17-Design

- `jugend/*.html`
  - lädt jetzt beide Stylesheets, ohne andere Websitebereiche zu beeinflussen

## Upload

1. ZIP entpacken.
2. Den gesamten Inhalt in das bestehende GitHub-Repository hochladen.
3. Nichts vorher löschen.
4. Gleichnamige Dateien ersetzen lassen.
5. Commit changes anklicken.
6. Nach dem Deployment die Seite mit Cmd + Shift + R neu laden.
