# SVK Live & Rekorde V1

Dieses Paket ergänzt:
- SVK Live-Center
- Countdown zum nächsten Heimspiel
- vorbereitete BFV-Bereiche
- Rekordseite
- Hall of Fame
- SVK-TV
- „Heute vor … Jahren“
- neue Links auf der Startseite
- responsive Gestaltung

## Wichtig
Die Live-Daten sind noch nicht aktiv. Spielplan, Tabelle und Ergebnisse werden erst
nach offizieller BFV-/Vereinsfreigabe automatisch eingebunden.

## Upload
1. ZIP entpacken.
2. Alles in das bestehende GitHub-Repository hochladen.
3. Nichts vorher löschen.
4. Gleichnamige Dateien ersetzen.
5. Mit Cmd + Shift + R neu laden.
