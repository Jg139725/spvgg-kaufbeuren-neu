# News V3 Komplettpaket

Dieses Paket enthält News V1, News V2 und News V3 gemeinsam.

## Enthalten
- moderne Newsübersicht
- Kategorien, Suche und Filter
- sechs ausführlich ausgearbeitete News-Detailseiten
- Autor und Lesedauer
- längere redaktionelle Artikel
- Zitatboxen
- Galerie-Bereiche
- ähnliche Beiträge
- Newsletter-Prototyp
- responsive Darstellung für Handy, Tablet und Desktop

## Wichtig
Das frühere News-V2-Paket muss nicht separat hochgeladen werden.

## Upload
1. ZIP entpacken.
2. Gesamten Inhalt in das bestehende GitHub-Repository hochladen.
3. Nichts vorher löschen.
4. Gleichnamige Dateien ersetzen lassen.
5. Nach dem Deployment mit Cmd + Shift + R neu laden.
