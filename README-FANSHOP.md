# Externer SVK-Fanshop

Dieses Paket verlinkt den Menüpunkt `Fanshop` direkt zum offiziellen externen Shop:

https://textilstars.com/SpVgg-Kaufbeuren

## Verhalten
- Klick auf Fanshop öffnet den offiziellen Shop in einem neuen Tab.
- Auf der SVK-Website selbst wird kein Shop nachgebaut.
- `fanshop.html` dient nur als Weiterleitung und Absicherung.
- Der externe Shop bleibt technisch und inhaltlich vollständig unabhängig.

## Upload
1. ZIP entpacken.
2. Alles in das bestehende GitHub-Repository hochladen.
3. Nichts vorher löschen.
4. Gleichnamige Dateien ersetzen.
5. Nach dem Deployment mit Strg/Cmd + Shift + R neu laden.
